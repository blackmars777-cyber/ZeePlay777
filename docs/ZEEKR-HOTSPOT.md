# 极氪车机热点

## 功能范围

极氪版本可在无线连接前或应用回到前台时，按驾驶员的设置启动车机热点。
优先使用检测到的原厂热点服务，复用系统已保存的热点配置，不自动更改名称、密码或关闭热点。
该原厂服务路径不要求 ADB；没有对应服务时，使用可用的平台接口及系统授权流程。
具体能力取决于车型、固件、Android 用户和服务权限，不以 OS 版本号单独判断支持情况。

## 使用方法

1. 在车机系统设置中配置热点。
2. 在应用中选择车机热点连接方式，保存匹配的热点信息。
3. 打开「设置 → 连接」中的自动车机热点选项。
4. 若系统要求授权，按页面提示完成；热点启动失败时，可通过页面入口手动打开系统热点设置。

开关默认关闭。开启后会按需检查并尝试启动热点；取消、离开前台或关闭开关会取消本次等待。
已有 CarPlay 会话、有线连接、Wi-Fi Direct 与现有 Wi-Fi 模式不会触发这项启动流程。
启动成功回调不等于网络已经可用，应用还会等待热点的实际状态。

## 排查

- 检查车机热点是否实际开启，以及 iPhone 加入的网络是否与保存的信息一致。
- 检查原厂服务是否可用、应用所在 Android 用户及系统授权。
- 服务拒绝、状态无法读取或启动超时，应显示对应结果；不通过反复请求或更改系统组件强行启动。
- 导出诊断报告前检查个人信息，不分享热点密码。

## 验证

主机测试覆盖服务调用、授权失败、取消、超时、异步回调及重试隔离。
实车需验证热点已开启、热点关闭、权限不足、启动中取消及休眠恢复等情形，
并确认应用退出或断开 CarPlay 不会关闭热点、影响其他热点客户端。
