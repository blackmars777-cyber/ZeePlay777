# 极氪 OS 7.2 界面规范

本方案面向极氪车机中的独立 Android CarPlay 应用。设计依据为用户提供的
《ZEEKR AI OS 7 HMI Design Guide》v1.1（2026-11-02），其中参数是非官方参考值。
实现目标是与 OS 7.2 协调，不声称使用原厂组件库或获得官方认证。

## 信息架构与关键页面

主页保留应用顶栏、欢迎区、双栏与卡下错误信息，仅更新视觉。
横屏采用连接主卡 + USB／设置辅助卡；窄屏纵向排列，
短横屏保留双列并允许内容滚动。CarPlay 自身画面维持原生投屏内容。
设置沿用按驾驶目标分类的结构，宽屏左侧分类、右侧内容独立滚动，窄屏先显示分类概览。

| 入口 | 内容与操作 |
| --- | --- |
| 主页 | 当前连接状态、连接／打开 CarPlay、选择 iPhone、断开、USB、设置 |
| 连接 | iPhone、无线／USB、自动连接、车机热点、权限 |
| 显示 | 深浅色、投屏尺寸、画质、系统栏 |
| 音频 | 媒体／导航音频流、缓冲 |
| 导航 | 位置共享；不展示 BYD HUD 或仪表提示 |
| 车辆 | 顶部 Zeekr 媒体中心／自动选源／播放控制；Siri 按键、驾驶侧、手势、车辆按钮 |
| 高级 | 提前显示极氪原生车辆数据；其他实验性显示与音频能力 |
| 诊断 | 真实诊断报告、权限与连接问题的排查入口 |

Zeekr 版的页面、搜索和首次向导排除 BYD／DiLink 导航、ADB 车辆探测、仪表投屏、
BYD 氛围灯和专用摇杆；已有 BYD 偏好不会使它们重新出现。标准版保持原配置入口。
Zeekr 原生数据读取继续受已验证车型／固件限制，媒体中心与车机热点继续使用已有真实服务。

## 组件规范

| 组件 | 外观、状态与行为 |
| --- | --- |
| 连接主卡 | 连接类型 → 状态文字＋图标或进度 → 核心操作 → 简要说明；状态不单靠颜色 |
| 普通卡片 | 设置组使用无描边容器与容器外的组标题，依靠背景明度区分；无发光、厚阴影或整屏玻璃效果 |
| 分类导航 | 中性色默认项；主文字＋黑灰图标和中性灰底块；侧栏无外框，192–288dp 随字号调整；支持 D-pad 焦点 |
| 设置选择行 | 无按钮外框，标题 · 当前值＋方向箭头；文字换行时增高；同一横向操作行保持同高 |
| 开关 | 统一右侧控件、可点击整行、名称／说明与状态关联；依赖项在主开关关闭时禁用 |
| 主操作 | 仅主任务使用实色强调；禁用时不可点击，按下有原生 ripple，焦点可见 |
| 轻量状态 | 图标＋简短文字，不添加虚假的网络、车速、电量或 HUD 状态 |
| 弹窗 | 与当前深浅色一致的低眩光浮层；已打开的弹窗保留编辑状态 |
| 下次连接提示 | 保存后标记待重新连接，提供现有重新连接入口，不擅自断开会话 |

## 状态与路径

| 状态 | 触发 | 呈现与下一步 |
| --- | --- | --- |
| 空状态 | 尚未选择 iPhone | 手机线性图标＋“尚未选择 iPhone”；选择手机或开始连接流程 |
| 就绪 | 已保存 iPhone、当前无会话 | 无线图标＋目标手机；连接／更换手机 |
| 加载 | 会话已启动但尚未激活 | 稳定进度指示＋正在连接文字；可打开投屏或断开 |
| 成功 | 会话 active | 勾选图标＋已连接文字；打开 CarPlay／断开 |
| 失败 | 认证配置错误或真实最近连接问题 | 错误图标＋说明，保留 USB／设置／权限恢复入口 |
| 权限不足／热点异常 | 实际服务结果 | 对应说明和系统授权／热点入口，沿用真实检测，不模拟状态 |

操作路径：主页 → 设置 → 车辆 → 车机联动 → 保存偏好 → 重新连接提示 → 用户主动重新连接。
关闭媒体中心接入后，自动选源和车机播放控制禁用；关闭自动选源仍允许用户主动选择 CarPlay。
三项新配置默认延续旧版行为；不会自动开启车辆电量、车速或驻车视频。

## 动效与系统协调

仅切换页面／分类时，对内容区使用 180ms ease-out 淡入；不对每次状态刷新重播进场动画。
原生按下 ripple 与开关过渡保持克制。遵循系统动画开关；系统动画为 0 时直接切换。
不添加无限呼吸灯、剧烈回弹或驾驶中自动弹出的大型装饰层。

不复制系统状态栏、空调 Dock、ADAS、仪表或原厂车控。系统栏、切口和键盘由实际
WindowInsets 留出安全区域，页面背景可延伸至边缘，交互内容始终位于安全区。
不固定“极氪 分辨率”；1600×1000 仅为设计参考画布，使用实际窗口 dp 与密度排版。
宽屏断点复用 SettingsLayoutPolicy，并随字体缩放提高所需宽度；窄屏与分屏允许滚动。

## 交付与验证

`common/build/reports/zeekr-settings-ui/`：浅色／深色、完整／紧凑、1.3 倍字体与阿拉伯语页面截图。
`common/build/reports/zeekr-hmi-states/`：参考横屏主页、完整／紧凑大字体、阿拉伯语与连接反馈状态样张；状态样张使用测试夹具，不是实车连接证据。
验证覆盖分类与搜索排除 BYD 信息、配置持久化、媒体开关的真实行为、颜色对比和文字边界。
运行仓库规定的 standard／zeekr 单元测试、lint 与 debug 构建。实车媒体中心注册、
方向盘事件、iPhone 音源切换与阳光下可读性仍需在对应极氪车型和 OTA 版本验收。

## 布局边界

主页的 USB、设置与版本号保持在右卡；热点操作与 iPhone 选择保持在无线左卡，
次级按钮上下排列。顶栏不增加系统时间、天气或假系统入口，也不引入侧栏、连接 Tab 或指引侧卡。
恢复“熟悉的驾乘体验。”及原有两行说明，紧凑窗口沿用原有折叠与滚动规则。
认证异常仍在双卡下方，以浅橙实体提示条展示；真实热点关闭时不再显示就绪状态。
标准版配色与投屏中的 CarPlay 内容保持原样。

## 辅助页面

连接设置与五步向导沿用现有顺序与选项，标题统一为 24sp，分组标题移到容器外，
当前步骤只用一段暖橙进度条强调。普通操作使用浅灰实体行，标题 · 当前值的选择行
仍保持无外框样式，避免把操作和说明文字混在一起。多行实色按钮增加 8dp 上下内边距；
同一横行的连接方式与向导操作按钮按最长文本等高，不改变保存或连接行为。

设置分类入口增加装饰性方向箭头，左侧当前分类保留中性选中底色并用暖橙细条标识。
需要处理的连接状态与待重新连接提示使用统一暖橙容器；真正连接成功才显示成功图标。
诊断、语言、关于沿用原有分类与已有文案，没有移动设置或新增默认开关。

备份页面的标题、无网络空状态和卡片与其他页面一致。二维码维持黑白对比和白色留白，
尺寸使用 dp 并同时按窗口与实际卡片可用宽度收敛，不再固定占用过宽的 264dp 方框。
备份服务、认证码、导入导出和报告访问逻辑保持原样。预览测试将备份网络状态固定为空，
不会启动备份监听或生成可用的访问凭据。

辅助页面的大字体、深浅色、窄窗口与阿拉伯语截图由界面测试生成并作为 CI 产物保存。
